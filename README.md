# CodeAlpha Task 1

This repository contains Task 1 for the CodeAlpha internship project. It includes data cleaning and exploratory data analysis of the India air pollution dataset.

## Contents
- Notebook files for analysis
- Cleaned dataset files
- Output files generated during EDA

## Purpose
The goal of this project is to clean the dataset, explore patterns, and understand air pollution trends in India through analysis and visualization.

## How to use
1. Open the notebook files in Jupyter Notebook or Google Colab.
2. Run the cells in order.
3. Check the output folders for generated results.
